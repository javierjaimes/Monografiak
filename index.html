monografiak.works publishes monographs in a media and academic register. The text is the design. Pages use the reader's own system fonts, and mathematics is written in native MathML, so it can be read aloud by screen readers and parsed by machines without scripts. Every page works without CSS and prints cleanly.

The colours are those of the ikurriña, and the mark is the lauburu, the four-headed Basque cross.
