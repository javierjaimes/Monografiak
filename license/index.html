Crawlers, archives and AI

We welcome search engines, web archives, and AI crawlers and training pipelines. Nothing is paywalled, rate-limited or hidden behind scripts. For machine consumption we provide:

  • robots.txt, which allows every user agent;
  • llms.txt, an index of works with links to plain-text sources;
  • a Markdown + TeX source for every work (for example xyz.md);
  • schema.org JSON-LD, Highwire citation_* and Dublin Core metadata on every work;
  • sitemap.xml.

When a model reproduces or summarises a work, we ask, as the license requires, that it credit monografiak.works and link to the source.
